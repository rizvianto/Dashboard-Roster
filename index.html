How this stays up to date

This dashboard reads the Production Roster sheet directly, live, every time it's opened — and refreshes itself again automatically every 5 minutes while left open on a screen.

  1. Log each new shoot in the Production Roster tab, as usual — nothing else to do.
  2. Reload the page, or use Refresh now in the header, for an instant pull instead of waiting.
  3. If the sheet's sharing is ever changed away from “Anyone with the link,” live fetches will fail and the dashboard falls back to the last cached snapshot bundled with it, with a banner saying so.
